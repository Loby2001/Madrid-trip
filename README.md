# Madrid 🇪🇸

Mappa personale dei luoghi da vedere a Madrid, con posizione GPS in tempo reale e percorso Google Maps in un tocco.

## Pubblicazione (GitHub Pages)

1. Carica **tutti** i file e la cartella `vendor/` nella root del repository.
2. Settings → Pages → Source: branch `main`, cartella `/ (root)`.
3. L'app sarà su `https://<utente>.github.io/<nome-repo>/`.

## Installazione sul telefono

- **iPhone**: apri il link in Safari → Condividi → "Aggiungi alla schermata Home".
- **Android**: apri il link in Chrome → menu ⋮ → "Installa app" / "Aggiungi a schermata Home".
- Alla prima apertura consenti l'accesso alla posizione.

## Aggiornare l'app

Quando modifichi i file, cambia `CACHE_NAME` in `sw.js` (es. `madrid-trip-v4`), così i telefoni scaricano la nuova versione.
